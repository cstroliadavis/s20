# Type Alias: CsvRow

> **CsvRow** = `string`[]

Represents a single parsed CSV row as an array of cell string values.

Used when parsing or writing CSV data as positional arrays rather than keyed objects.

## Example

```ts
const row: CsvRow = ['Alice', '30', 'New York'];
// A 3-column row
```
