# Function: getTodayDateString()

> **getTodayDateString**(`date?`): `string`

Returns current date formatted as YYYY-MM-DD.

## Parameters

### date?

`Date`

Reference date object

## Returns

`string`

Current date string

## Example

```ts
const today = getTodayDateString();
// Returns today's date formatted as 'YYYY-MM-DD'
```
